# Akari Language Support for VS Code

This extension provides syntax highlighting and language support for the **Akari** programming language.

## Installation

Since this extension is not yet published on the Marketplace, you can install it manually:

1. Download the latest `.vsix` file (e.g., `akari-lang-1.0.0.vsix`) from this folder.
2. Open VS Code.
3. Go to the Extensions view (Ctrl+Shift+X).
4. Click on the three dots `...` in the top right corner.
5. Select **"Install from VSIX..."** and choose the downloaded file.
6. Restart VS Code.

## Features
- Syntax highlighting for keywords (`let`, `mut`, `def`, `end`, etc.).
- String and comment highlighting.
- Auto-closing brackets and parentheses.
