# Akari

> A teaching programming language in 18 keywords.
> Simple, intuitive, powerful.

**Status:** alpha · **Version:** 0.4.0 · **License:** Apache-2.0


## What is Akari?

Akari is a small programming language designed for learning.
It has 18 keywords, immutable variables by default, and typed buffers.

Built because Python's indentation was hard on the eyes.


## Install

```bash
npm install -g akari-lang
