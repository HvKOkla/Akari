# Standard Library (`std_akari`)

Welcome to the official standard library for the **Akari** programming language. 

Unlike the core engine (`/src`), which is permanently frozen to ensure 10+ years of strict backward compatibility, this standard library is open for community contributions, new modules, and enhancements.

**Contributing**

Want to add a new module (e.g., text manipulation, advanced mathematics, file utilities)? Check out our Contributing Guidelines to submit a Pull Request on Codeberg
